# Reporting Security Issues

If you discover a security issue in this fork, please report it **privately** using
[GitHub private vulnerability reporting](https://github.com/yartat/IdentityServer4/security/advisories/new)
("Security" tab → "Report a vulnerability"). Do not open a public issue or pull request for it.

This lets us assess the risk and make a fix available before the details become public. The project is maintained on a
best-effort basis without a support agreement: we aim to acknowledge a report promptly and to fix confirmed issues in the next
release. Only the latest release is supported.

Issues that also affect the original IdentityServer4 4.x or Duende IdentityServer should additionally be reported to their maintainers.
